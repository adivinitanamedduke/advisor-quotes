# Assumptions

Where the brief was silent or ambiguous, this is what was decided and why. Every row is also summarised in the README "Assumptions" section; update both in the same commit.

| ID | Ambiguity | Assumption | Why | Where |
|---|---|---|---|---|
| A-01 | Brief says ".NET 8 or later" | .NET 10 (current LTS) | Latest LTS, longest support window | `global.json`, all `.csproj` |
| A-02 | Currency and premium frequency not stated | South African Rand (ZAR), monthly premium | Sanlam Connect is a South African business; life products are usually quoted monthly | `Pricing:Currency`, `Quote.MonthlyPremium` |
| A-03 | Auth is out of scope, but quotes belong to an adviser | Adviser id comes from the `X-Adviser-Id` request header; missing header is 400 | Keeps ownership and "who changed it" real without building auth; swaps for a JWT claim later with no service change | `API/Controllers/Public/BaseController.cs` |
| A-04 | "Internal identifier" vs "external reference" | `Id` (Guid) is internal and never exposed; `Identifier` (Guid) is the public route id; `Reference` (`QT-000123`) is the human readable reference generated by a database sequence | Separates storage keys from API ids, and gives advisers something they can read out to a client | `QuoteConfiguration` |
| A-05 | Allowed status transitions | Draft to SentToClient or Declined; SentToClient to Accepted or Declined; Accepted and Declined are final. Same status again is rejected | Matches a simple sales flow; final states stop silent rewrites of an accepted quote | Quote status machine (quote lifecycle) |
| A-06 | "Short window" for duplicates | 10 minutes, configurable via `Idempotency__WindowMinutes` | Long enough to cover double clicks and client retries, short enough that a deliberate re-quote later is allowed | `IdempotencyOptions` |
| A-07 | Visibility of other advisers' quotes | Each adviser sees only their own quotes; another adviser's identifier returns 404, not 403 | Does not reveal that the quote exists | Repository queries are adviser scoped |
| A-08 | Status codes for rule breaches | Validation and business rule breaches (bad transition, product limits) are 400; 409 is only for an Idempotency-Key reused with a different body or a concurrent update clash | One consistent rule: 400 means "fix your request", 409 means "the resource changed under you" | `ApiExceptionHandlerAttribute` |
| A-09 | Product catalogue not specified | Three illustrative products (TERM_LIFE, FUNERAL, DISABILITY) with limits and base rates held in configuration | Shows pricing is data driven; real rates would come from an actuarial table | `API/appsettings.json` `Pricing` |
| A-10 | Local machine has no Docker | Integration tests use `TEST_POSTGRES_CONNECTION` when set, else Testcontainers when Docker is available, else they are skipped with a clear message | Reviewers with Docker get one command; machines with a native Postgres still run them | `Tests.Integration` |
| A-14 | What counts as "the same submission" without an Idempotency-Key | Same adviser, client (name trimmed, whitespace collapsed, case-insensitive; date of birth; smoker), product (code case-insensitive; cover amount; term) and notes (trimmed, blank = none). Premium is not part of it | Catches double clicks and retries that differ only cosmetically; any material change is a new quote | `Business/Services/Quotes/QuoteFingerprint.cs` |
| A-15 | A new Idempotency-Key sent with a body identical to a quote created inside the window | Treated as a replay of that quote (200), because the key lookup runs first and the fingerprint window second | A retry from a client that regenerates its key per attempt is still a double submit; a deliberate re-quote can wait out the window or change the notes | `QuoteRepository.AddUnlessDuplicateAsync` |
